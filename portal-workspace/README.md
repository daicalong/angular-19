# PortalWorkspace

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.2.0.

To get started, use command `cd projects/portal` `npm i` & `ng s`.

## Framework & Architecture

This project contain the following 3 major components.

- Angular workspace that can support multi-project applications within it.
- TailwindCSS v3 (v4 is not "clean" enough yet. So we'll hold off on it for a while).
- PrimeNG - an Angular-native UI framework that is extendable & customizable. Check out the doucmentation here [PrimeNG](https://primeng.org/)
